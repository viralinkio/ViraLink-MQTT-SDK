# Phase 6b: STM32 Port and SPI NOR Flash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** STM32 (STM32duino 2.x) becomes a supported target in the Standard profile. It gets a client ID, entropy,
health, a wall clock the application can set, and persistence and credentials on SPI NOR flash, as the design
decides ("SPI NOR flash on STM32 boards"). OTA through MCUboot is Phase 6c.

**Architecture:** A platform-free flash stack in `src/vl/flash/`, host-tested against a NOR emulator:
`IFlash` (erased = 0xFF, programming clears bits, block erase) with `FlashRegion` to split one chip;
`FlashOutboxStore` (an `IOutboxStore`, so `vl::Persistence` runs on it unchanged); `FlashKvStore` (an
`IKeyValueStore` that survives power cuts); `W25qFlash`, a driver over `ISpiDevice` with an Arduino `SPIClass`
adapter. Usable on any target with SPI, not only STM32. The STM32 platform code lives in
`src/vl/platform/stm32/`.

**Tech Stack:** C++11; host Unity tests (test_flash, test_flash_kv, test_w25q); STM32 build-verified
(`nucleo_f401re`).

## Decisions

- **Detection**: `VL_PLATFORM_STM32` = `defined(ARDUINO_ARCH_STM32)`. No RTOS assumed: `NullLock`, no
  `startTask()`.
- **Client ID** from the 96-bit unique ID (`HAL_GetUIDw0..2`), folded to 48 bits: stable across boots.
- **Entropy**: the RNG peripheral where the chip has one (`RNG` defined), read through its registers with a
  bounded wait; on a clock or seed error, or a chip without it (F401), an xorshift seeded from the UID and
  `micros()`. Jitter only needs devices to differ.
- **Wall clock**: `vl::setUtcMs(ms)` for any platform. ESP32/ESP8266 set the system time; elsewhere the
  platform clock keeps the offset from uptime (`UtcOffset`, host-tested). The source is the app's: NTP over
  UDP, a modem (`AT+CCLK`), an RTC. Until it is set, records go without `ts` and are restamped once it is.
- **Health**: free heap = gap between the stack pointer and the heap break, plus `mallinfo().fordblks`; reset
  reason from the RCC flags (each flag behind `#ifdef`, names vary by family), read once and then cleared so
  the next reset is told apart.
- **`IFlash`**: `size()`, `eraseSize()`, `read`, `program` (any length; the driver splits pages and returns once
  the bytes are durable), `erase(addr)` of one block. `FlashRegion(flash, offset, size)` gives the outbox, the
  key-value store and (6c) an OTA slot their own windows on one chip.
- **`FlashOutboxStore(flash, segments = 8, segmentSize = 4096)`**: segment = whole erase blocks; `sync()` is a
  no-op because `program()` is already durable. The count is clamped to what fits.
- **`FlashKvStore(flash)`**: the flash is split into two banks. Each bank is a header
  (`magic, generation, crc16`) and an append-only log of records
  (`keyLen | valLen | key | value | crc16`; `keyLen` bit 7 = deleted). The last record for a key wins. A torn
  record fails its CRC and ends the log; the next write compacts first. When a bank is full, the live records
  and the new one are copied into the erased other bank, and its header is written last: the commit point.
  The valid header with the higher generation wins at mount. Writing a value equal to the stored one writes
  nothing. Lazy mount on first use (the SPI bus may start after construction).
- **`W25qFlash(spi)`**: JEDEC ID (`0x9F`) gives the size (up to 16 MB, 3-byte addresses); release from power-down
  (`0xAB`) at `begin()`; read `0x03`; page program `0x02` within 256-byte pages; 4 KB sector erase `0x20`; write
  enable before each; busy polled on status `0x05` with timeouts (page 10 ms, sector 1 s) and
  `platformYield()`. Works with W25Q, GD25Q, MX25L and other JEDEC parts that share these commands.
- **`ArduinoSpi(SPIClass&, csPin, hz)`**: `ISpiDevice` with a transaction per command.
- **Examples**: `stm32_flash`: W5500 Ethernet + StreamMqtt, persistence and a credentials store on a W25Q.
  `build_examples.sh` reads a `// Libraries:` line into `lib_deps`.
