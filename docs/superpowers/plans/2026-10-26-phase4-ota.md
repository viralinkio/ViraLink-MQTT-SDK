# Phase 4: OTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `vl::Ota` module that installs ThingsBoard OTA packages: it reports the running firmware, discovers the
assigned package, downloads it over MQTT chunks or from `fw_url` over HTTP(S), checks it with any of the seven
ThingsBoard checksum algorithms while it is written, activates it, restarts, and on ESP32 confirms or rolls back the
new image. The engine is heap-free and tested on the host; ESP32 gets the flash and HTTP ports.

**Architecture:** Streaming checksums live in `core/Hash` (platform-free, golden-tested against Guava, the library
ThingsBoard hashes packages with). The module `api/Ota` is an `ApiModule` that subscribes to shared-attribute updates,
attribute responses and firmware chunks. It writes through two new platform interfaces in `pal/Firmware.h`:
`IFirmwareWriter` (inactive slot, boot selection, confirm/rollback) and `IHttpSource` (ranged HTTP reads). ESP32
implements both in `platform/esp32/EspOta` over `esp_ota_ops` and `esp_http_client`; host tests use fakes. The router
now delivers shared-attribute updates to every subscriber, so OTA and `SharedAttributes` can be attached together.

**Tech Stack:** C++11 (`-std=gnu++11`), PlatformIO `native` + Unity, ASan/UBSan, `-Werror`; ESP-IDF `esp_ota_ops`,
`esp_http_client`.

## Global Constraints

- C++11 in `src/`; no heap, `std::string`, `std::function` or exceptions after `begin()`. ESP-IDF calls that allocate
  internally (`esp_http_client`, like `esp_mqtt_client` in `EspMqtt`) are confined to `platform/esp32`.
- Capacities are `VL_*` macros in `Config.h`; strings kept beyond a call are copied into fixed buffers.
- Callbacks are function pointers plus `void* ctx`, fired on the client task with no lock held.
- Hold the client lock only around outbox and table access: never during network I/O, flash writes or a callback.
- Every payload shape lives in `core/Codec` with a golden-string test.
- `fw_state`, `current_fw_*`, package requests and chunk requests use `RecordClass::Control`: never dropped.
- OTA compiles only when `VL_ENABLE_OTA` is set (off in the Lite profile, so AVR never builds the module).
- Portable to every target: in `src/` outside `platform/`, no C++ standard library headers, no `printf` of floats or
  `%ll`/`%z`, no shifts of promoted 8/16-bit values past 15 bits (AVR `int` is 16-bit), no identifiers that Arduino.h
  defines as macros (`min`, `max`, `abs`, `round`, `bit`, …).
- Gate: `pio test -e native`, `scripts/check_portability.sh` and `scripts/build_examples.sh` pass.
- Commits: only when the user asks (the repository has no commits yet).

## Wire format (ThingsBoard v2 firmware protocol)

| Direction | Topic | Payload |
| --- | --- | --- |
| out | `v1/devices/me/telemetry` | `{"current_fw_title":"ViraGate","current_fw_version":"2.3.0"}`, first Online per boot |
| out | `v1/devices/me/attributes/request/{id}` | `{"sharedKeys":"fw_title,fw_version,fw_size,fw_checksum,fw_checksum_algorithm,fw_url"}`, every Online |
| in | `v1/devices/me/attributes/response/{id}` | `{"shared":{"fw_title":…,"fw_version":…,"fw_size":…,"fw_checksum_algorithm":"SHA256","fw_checksum":…}}`, or `{}` when nothing is assigned |
| in | `v1/devices/me/attributes` | the same keys when a package is assigned; `{"deleted":["fw_title",…]}` when unassigned |
| out | `v2/fw/request/{req}/chunk/{n}` | chunk size as decimal text, e.g. `960` |
| in | `v2/fw/response/{req}/chunk/{n}` | raw image bytes `[n*size, (n+1)*size)`; empty past the end |
| out | `v1/devices/me/telemetry` | `{"fw_state":"DOWNLOADING"}` … `{"fw_state":"FAILED","fw_error":"checksum mismatch"}` |

Checksums are compared case-insensitively with Guava's `HashCode.toString()`: digest bytes in order, lowercase hex.
CRC32 and Murmur3 therefore come out little-endian (`zlib.crc32("abc")` is `352441c2`; ThingsBoard prints `c2412435`).

## Decisions

- **Golden values come from Guava 33.6** (`/usr/share/java/maven/lib/guava-33.6.0-jre.jar`), the hash library of
  ThingsBoard's `BaseOtaPackageService.generateChecksum`. `murmur3_32` and `murmur3_32_fixed` agree for byte input.
  The Phase 6 integration suite repeats the check against a live server.
- **Chunk size** = the transport's `maxPacket()`, capped at the server's 64 KB limit, minus 64 bytes for the topic and
  MQTT header; `VL_OTA_CHUNK_SIZE` can only lower it. With the 4 KB ESP32 buffer that is 4032 bytes. A chunk shorter
  than requested before the end fails the update, since the server derives offsets from the requested size.
- **Chunk requests go through the outbox** like every other publish. After a reconnect the module asks again with a
  new request id; responses for any id issued during the current download are accepted for the expected chunk, and
  everything else (earlier downloads, duplicates of chunks already written) is dropped. No request is sent offline.
- **UPDATED** is reported once per boot whenever the assigned package equals the running firmware. That covers images
  that had no rollback support as well as confirmed ones.
- **Confirmation and rollback (ESP32).** A new image waiting for confirmation is confirmed on its first Online. If it is
  not online within `VL_OTA_CONFIRM_TIMEOUT_MS` (5 min) it is rolled back. After a boot that follows a rollback, the
  first differing package is reported FAILED "rolled back" instead of installed, so a bad build cannot loop.
- **A failed package is not retried** until it is unassigned and assigned again, another one is assigned, or the device
  restarts. Invalid packages (unknown algorithm, no checksum, no size) fail the same way.
- **Restart** happens once fw_state UPDATING has been delivered (outbox empty), or after `VL_OTA_RESTART_DELAY_MS`.
- **fw_url downloads** run in `tick()`, one `VL_OTA_HTTP_BLOCK` read per loop. A broken connection is reopened with a
  `Range` from the bytes written; a server that ignores the Range restarts the image from byte 0. They run while MQTT
  is offline too.
- **Not in this phase:** resume after a reboot (needs `IKeyValueStore`, Phase 5), flash and HTTP ports for ESP8266 and
  STM32 (Phase 6), software OTA (`sw_*`, v2.x), gateway sub-device OTA.

```cpp
// Hasher can keep them in one union.
#pragma once

#include <stddef.h>
#include <stdint.h>

namespace vl {
namespace hash {

struct Md5State {
  uint32_t h[4];
  uint64_t len;
  uint8_t buf[64];
};
void md5Init(Md5State& s);
void md5Update(Md5State& s, const uint8_t* p, size_t n);
void md5Final(Md5State& s, uint8_t out[16]);

struct Sha256State {
  uint32_t h[8];
  uint64_t len;
  uint8_t buf[64];
};
void sha256Init(Sha256State& s);
void sha256Update(Sha256State& s, const uint8_t* p, size_t n);
void sha256Final(Sha256State& s, uint8_t out[32]);

// SHA-512, or SHA-384 (other initial values, digest cut to 48 bytes).
struct Sha512State {
  uint64_t h[8];
  uint64_t len;  // bytes; firmware images never reach 2^61
  uint8_t buf[128];
};
void sha512Init(Sha512State& s, bool sha384);
void sha512Update(Sha512State& s, const uint8_t* p, size_t n);
void sha512Final(Sha512State& s, uint8_t out[64]);

uint32_t crc32Update(uint32_t crc, const uint8_t* p, size_t n);  // start with 0xFFFFFFFF, finish with ~

// MurmurHash3 x86_32 and x64_128, seed 0 (Guava murmur3_32 / murmur3_128).
struct Murmur32State {
  uint32_t h;
  uint32_t len;
  uint8_t tail[4];
};
void murmur32Init(Murmur32State& s);
void murmur32Update(Murmur32State& s, const uint8_t* p, size_t n);
uint32_t murmur32Final(Murmur32State& s);

struct Murmur128State {
  uint64_t h1;
  uint64_t h2;
  uint64_t len;
  uint8_t tail[16];
};
void murmur128Init(Murmur128State& s);
void murmur128Update(Murmur128State& s, const uint8_t* p, size_t n);
void murmur128Final(Murmur128State& s, uint64_t& h1, uint64_t& h2);

}  // namespace hash
}  // namespace vl
```

```cpp
// Checksums for OTA images, computed while the image streams into flash.
#pragma once

#include <stddef.h>
#include <stdint.h>

#include "vl/core/HashAlgos.h"

namespace vl {

// The algorithms ThingsBoard offers for an OTA package (fw_checksum_algorithm).
enum class HashAlgo : uint8_t { Md5, Sha256, Sha384, Sha512, Crc32, Murmur3_32, Murmur3_128 };

// "MD5", "SHA256", "SHA384", "SHA512", "CRC32", "MURMUR3_32", "MURMUR3_128".
// False if name is null or unknown.
bool parseHashAlgo(const char* name, HashAlgo& out);

class Hasher {
 public:
  // SHA-512 as hex plus the NUL.
  static const size_t kHexSize = 129;

  void begin(HashAlgo algo);
  void update(const uint8_t* p, size_t n);
  // Ends the hash and writes the lowercase hex digest the way ThingsBoard
  // prints it (Guava HashCode.toString(): digest bytes in order, so CRC32 and
  // Murmur3 come out little-endian). out needs kHexSize bytes. Returns the
  // number of hex characters. Call begin() before hashing again.
  size_t hex(char* out);

 private:
  HashAlgo algo_ = HashAlgo::Md5;
  union State {
    hash::Md5State md5;
    hash::Sha256State sha256;
    hash::Sha512State sha512;
    uint32_t crc32;
    hash::Murmur32State m32;
    hash::Murmur128State m128;
  } s_;
};

}  // namespace vl
```

```cpp
#include "vl/core/Hash.h"

#include <string.h>

namespace vl {

namespace {

struct AlgoName {
  const char* name;
  HashAlgo algo;
};
const AlgoName kAlgos[] = {
    {"MD5", HashAlgo::Md5},           {"SHA256", HashAlgo::Sha256},         {"SHA384", HashAlgo::Sha384},
    {"SHA512", HashAlgo::Sha512},     {"CRC32", HashAlgo::Crc32},           {"MURMUR3_32", HashAlgo::Murmur3_32},
    {"MURMUR3_128", HashAlgo::Murmur3_128},
};

size_t toHex(const uint8_t* d, size_t n, char* out) {
  static const char kDigits[] = "0123456789abcdef";
  for (size_t i = 0; i < n; ++i) {
    out[2 * i] = kDigits[d[i] >> 4];
    out[2 * i + 1] = kDigits[d[i] & 15];
  }
  out[2 * n] = '\0';
  return 2 * n;
}

void putLe32(uint8_t* p, uint32_t v) {
  for (int i = 0; i < 4; ++i) p[i] = static_cast<uint8_t>(v >> (8 * i));
}

void putLe64(uint8_t* p, uint64_t v) {
  for (int i = 0; i < 8; ++i) p[i] = static_cast<uint8_t>(v >> (8 * i));
}

}  // namespace

bool parseHashAlgo(const char* name, HashAlgo& out) {
  if (!name) return false;
  for (size_t i = 0; i < sizeof(kAlgos) / sizeof(kAlgos[0]); ++i) {
    if (strcmp(name, kAlgos[i].name) == 0) {
      out = kAlgos[i].algo;
      return true;
    }
  }
  return false;
}

void Hasher::begin(HashAlgo algo) {
  algo_ = algo;
  switch (algo) {
    case HashAlgo::Md5:
      hash::md5Init(s_.md5);
      break;
    case HashAlgo::Sha256:
      hash::sha256Init(s_.sha256);
      break;
    case HashAlgo::Sha384:
    case HashAlgo::Sha512:
      hash::sha512Init(s_.sha512, algo == HashAlgo::Sha384);
      break;
    case HashAlgo::Crc32:
      s_.crc32 = 0xFFFFFFFFul;
      break;
    case HashAlgo::Murmur3_32:
      hash::murmur32Init(s_.m32);
      break;
    case HashAlgo::Murmur3_128:
      hash::murmur128Init(s_.m128);
      break;
  }
}

void Hasher::update(const uint8_t* p, size_t n) {
  switch (algo_) {
    case HashAlgo::Md5:
      hash::md5Update(s_.md5, p, n);
      break;
    case HashAlgo::Sha256:
      hash::sha256Update(s_.sha256, p, n);
      break;
    case HashAlgo::Sha384:
    case HashAlgo::Sha512:
      hash::sha512Update(s_.sha512, p, n);
      break;
    case HashAlgo::Crc32:
      s_.crc32 = hash::crc32Update(s_.crc32, p, n);
      break;
    case HashAlgo::Murmur3_32:
      hash::murmur32Update(s_.m32, p, n);
      break;
    case HashAlgo::Murmur3_128:
      hash::murmur128Update(s_.m128, p, n);
      break;
  }
}

size_t Hasher::hex(char* out) {
  uint8_t d[64];
  switch (algo_) {
    case HashAlgo::Md5:
      hash::md5Final(s_.md5, d);
      return toHex(d, 16, out);
    case HashAlgo::Sha256:
      hash::sha256Final(s_.sha256, d);
      return toHex(d, 32, out);
    case HashAlgo::Sha384:
      hash::sha512Final(s_.sha512, d);
      return toHex(d, 48, out);
    case HashAlgo::Sha512:
      hash::sha512Final(s_.sha512, d);
      return toHex(d, 64, out);
    case HashAlgo::Crc32:
      putLe32(d, ~s_.crc32);
      return toHex(d, 4, out);
    case HashAlgo::Murmur3_32:
      putLe32(d, hash::murmur32Final(s_.m32));
      return toHex(d, 4, out);
    case HashAlgo::Murmur3_128: {
      uint64_t h1, h2;
      hash::murmur128Final(s_.m128, h1, h2);
      putLe64(d, h1);
      putLe64(d + 8, h2);
      return toHex(d, 16, out);
    }
  }
  out[0] = '\0';
  return 0;
}

namespace {

// Reflected polynomial 0xEDB88320, four bits per step: a 64-byte table
// instead of 1 KB.
const uint32_t kCrcNibble[16] = {
    0x00000000ul, 0x1DB71064ul, 0x3B6E20C8ul, 0x26D930ACul, 0x76DC4190ul, 0x6B6B51F4ul, 0x4DB26158ul, 0x5005713Cul,
    0xEDB88320ul, 0xF00F9344ul, 0xD6D6A3E8ul, 0xCB61B38Cul, 0x9B64C2B0ul, 0x86D3D2D4ul, 0xA00AE278ul, 0xBDBDF21Cul,
};

uint32_t rotl32(uint32_t x, unsigned r) { return (x << r) | (x >> (32 - r)); }
uint64_t rotl64(uint64_t x, unsigned r) { return (x << r) | (x >> (64 - r)); }

uint32_t le32(const uint8_t* p) {
  return static_cast<uint32_t>(p[0]) | static_cast<uint32_t>(p[1]) << 8 | static_cast<uint32_t>(p[2]) << 16 |
         static_cast<uint32_t>(p[3]) << 24;
}

uint64_t le64(const uint8_t* p) { return static_cast<uint64_t>(le32(p)) | static_cast<uint64_t>(le32(p + 4)) << 32; }

const uint32_t kM32C1 = 0xcc9e2d51ul;
const uint32_t kM32C2 = 0x1b873593ul;

uint32_t m32Mix(uint32_t k) {
  k *= kM32C1;
  k = rotl32(k, 15);
  return k * kM32C2;
}

const uint64_t kM128C1 = 0x87c37b91114253d5ull;
const uint64_t kM128C2 = 0x4cf5ad432745937full;

uint64_t m128MixK1(uint64_t k) {
  k *= kM128C1;
  k = rotl64(k, 31);
  return k * kM128C2;
}

uint64_t m128MixK2(uint64_t k) {
  k *= kM128C2;
  k = rotl64(k, 33);
  return k * kM128C1;
}

uint64_t fmix64(uint64_t k) {
  k ^= k >> 33;
  k *= 0xff51afd7ed558ccdull;
  k ^= k >> 33;
  k *= 0xc4ceb9fe1a85ec53ull;
  k ^= k >> 33;
  return k;
}

void m128Block(Murmur128State& s, const uint8_t* p) {
  s.h1 ^= m128MixK1(le64(p));
  s.h1 = rotl64(s.h1, 27) + s.h2;
  s.h1 = s.h1 * 5 + 0x52dce729u;
  s.h2 ^= m128MixK2(le64(p + 8));
  s.h2 = rotl64(s.h2, 31) + s.h1;
  s.h2 = s.h2 * 5 + 0x38495ab5u;
}

}  // namespace

uint32_t crc32Update(uint32_t crc, const uint8_t* p, size_t n) {
  for (size_t i = 0; i < n; ++i) {
    crc ^= p[i];
    crc = (crc >> 4) ^ kCrcNibble[crc & 15];
    crc = (crc >> 4) ^ kCrcNibble[crc & 15];
  }
  return crc;
}

void murmur32Init(Murmur32State& s) {
  s.h = 0;
  s.len = 0;
}

void murmur32Update(Murmur32State& s, const uint8_t* p, size_t n) {
  for (size_t i = 0; i < n; ++i) {
    s.tail[s.len & 3] = p[i];
    ++s.len;
    if ((s.len & 3) != 0) continue;
    s.h ^= m32Mix(le32(s.tail));
    s.h = rotl32(s.h, 13);
    s.h = s.h * 5 + 0xe6546b64ul;
  }
}

uint32_t murmur32Final(Murmur32State& s) {
  uint32_t k = 0;
  switch (s.len & 3) {
    case 3:
      k ^= static_cast<uint32_t>(s.tail[2]) << 16;
      // fall through
    case 2:
      k ^= static_cast<uint32_t>(s.tail[1]) << 8;
      // fall through
    case 1:
      k ^= s.tail[0];
      s.h ^= m32Mix(k);
      break;
    default:
      break;
  }
  uint32_t h = s.h ^ s.len;
  h ^= h >> 16;
  h *= 0x85ebca6bul;
  h ^= h >> 13;
  h *= 0xc2b2ae35ul;
  h ^= h >> 16;
  return h;
}

void murmur128Init(Murmur128State& s) {
  s.h1 = 0;
  s.h2 = 0;
  s.len = 0;
}

void murmur128Update(Murmur128State& s, const uint8_t* p, size_t n) {
  size_t used = static_cast<size_t>(s.len & 15);
  s.len += n;
  if (used) {
    size_t take = 16 - used < n ? 16 - used : n;
    memcpy(s.tail + used, p, take);
    p += take;
    n -= take;
    if (used + take < 16) return;
    m128Block(s, s.tail);
  }
  for (; n >= 16; p += 16, n -= 16) m128Block(s, p);
  memcpy(s.tail, p, n);
}

void murmur128Final(Murmur128State& s, uint64_t& h1, uint64_t& h2) {
  size_t rem = static_cast<size_t>(s.len & 15);
  uint64_t k1 = 0, k2 = 0;
  for (size_t i = rem; i-- > 8;) k2 ^= static_cast<uint64_t>(s.tail[i]) << (8 * (i - 8));
  for (size_t i = rem < 8 ? rem : 8; i-- > 0;) k1 ^= static_cast<uint64_t>(s.tail[i]) << (8 * i);
  if (rem > 8) s.h2 ^= m128MixK2(k2);
  if (rem > 0) s.h1 ^= m128MixK1(k1);
  h1 = s.h1 ^ s.len;
  h2 = s.h2 ^ s.len;
  h1 += h2;
  h2 += h1;
  h1 = fmix64(h1);
  h2 = fmix64(h2);
  h1 += h2;
  h2 += h1;
}

}  // namespace hash
}  // namespace vl
```

```cpp
void block(uint32_t h[4], const uint8_t* p) {
  uint32_t m[16];
  for (int i = 0; i < 16; ++i) {
    m[i] = static_cast<uint32_t>(p[4 * i]) | static_cast<uint32_t>(p[4 * i + 1]) << 8 |
           static_cast<uint32_t>(p[4 * i + 2]) << 16 | static_cast<uint32_t>(p[4 * i + 3]) << 24;
  }
  uint32_t a = h[0], b = h[1], c = h[2], d = h[3];
  for (unsigned i = 0; i < 64; ++i) {
    uint32_t f;
    unsigned g;
    if (i < 16) {
      f = (b & c) | (~b & d);
      g = i;
    } else if (i < 32) {
      f = (d & b) | (~d & c);
      g = (5 * i + 1) & 15;
    } else if (i < 48) {
      f = b ^ c ^ d;
      g = (3 * i + 5) & 15;
    } else {
      f = c ^ (b | ~d);
      g = (7 * i) & 15;
    }
    uint32_t t = d;
    d = c;
    c = b;
    b += rotl(a + f + kK[i] + m[g], kShift[(i / 16) * 4 + (i & 3)]);
    a = t;
  }
  h[0] += a;
  h[1] += b;
  h[2] += c;
  h[3] += d;
}

  uint8_t len[8];
  for (int i = 0; i < 8; ++i) len[i] = static_cast<uint8_t>(bits >> (8 * i));
  md5Update(s, len, 8);
  for (int i = 0; i < 16; ++i) out[i] = static_cast<uint8_t>(s.h[i / 4] >> (8 * (i & 3)));
}
```

```cpp
  virtual bool rolledBack() { return false; }
```

```cpp
// fw_state values in the order an update reaches them; Idle is never reported.
enum class OtaState : uint8_t { Idle, Downloading, Downloaded, Verified, Updating, Updated, Failed };
const char* toString(OtaState s);  // "DOWNLOADING", ...

// error is set for Failed and null otherwise; valid during the call.
typedef void (*OtaStateCb)(OtaState state, const char* error, void* ctx);
// total is 0 when the size is unknown (an fw_url package without fw_size).

// Firmware OTA over the ThingsBoard v2 firmware protocol.
//  - On the first Online after boot: reports current_fw_title/_version and
//    confirms a new image that is waiting for it (ESP32 rollback).
//  - On every Online, and on each fw_* shared-attribute update: reads the
//    assigned package. A package equal to the running firmware is reported
//    UPDATED (once per boot); any other is downloaded over MQTT chunks, or
//    over HTTP(S) when it has fw_url, hashed while it is written, verified,
//    activated, and the device restarts.
//  - A failed package is not tried again until it is unassigned and assigned
//    again, another one is assigned, or the device restarts.
// Runs on the client task; register callbacks before client.begin().
class Ota : public ApiModule {
 public:
  Ota();

  // The running firmware (copied). Required: until it is set the module does
  // nothing. Call before client.begin().

  // Defaults: platformFirmwareWriter() and platformHttpSource().
  void setWriter(IFirmwareWriter& w) { writer_ = &w; }
  void setHttp(IHttpSource& h) { http_ = &h; }
  // Trust anchors for fw_url downloads; default: the client's Config::tls.
  void setHttpTls(const ITlsProvider* tls) { httpTls_ = tls; }
  void onState(OtaStateCb cb, void* ctx) {
    stateCb_ = cb;
    stateCtx_ = ctx;
  }
  void onProgress(OtaProgressCb cb, void* ctx) {
    progressCb_ = cb;
    progressCtx_ = ctx;
  }
  // Last reported state.
  OtaState state() const { return state_; }

  void topics(TopicSink& sink) override;
  bool handle(const Topic& topic, Bytes payload) override;
  void onOnline() override;
  void tick(uint64_t nowMs) override;
  void onDetach() override;

 private:
  enum class Phase : uint8_t { Idle, Downloading, Updating, Updated, Failed };

  struct Target {
    char title[VL_OTA_TITLE_SIZE];
    char version[VL_OTA_VERSION_SIZE];
    char checksum[Hasher::kHexSize];

  void abortDownload();
  void fail(const char* error);
```

```cpp
#include <string.h>

#include "vl/Client.h"
#include "vl/Log.h"
#include "vl/core/Codec.h"

namespace vl {

namespace {

const char kTargetKeys[] = "fw_title,fw_version,fw_size,fw_checksum,fw_checksum_algorithm,fw_url";
// Topic and MQTT header of a chunk response, v2/fw/response/<id>/chunk/<n>.
const size_t kChunkOverhead = 64;
// ThingsBoard refuses a chunk larger than NETTY_MAX_PAYLOAD_SIZE.
const uint32_t kServerMaxPayload = 65536ul;

// Absent stays "", which is fine; present but not a string or too long fails.
bool copyAttr(JsonValue v, char* out, size_t cap) {
  out[0] = '\0';
  return !v.valid() || v.copyString(out, cap);
}

// Checksums typed into the ThingsBoard UI may be upper case.
bool equalsHex(const char* a, const char* b) {
  for (;; ++a, ++b) {
    char x = *a >= 'A' && *a <= 'F' ? static_cast<char>(*a - 'A' + 'a') : *a;
    char y = *b >= 'A' && *b <= 'F' ? static_cast<char>(*b - 'A' + 'a') : *b;
    if (x != y) return false;
    if (!x) return true;
  }
}

}  // namespace

const char* toString(OtaState s) {
  switch (s) {
    case OtaState::Idle:
      return "IDLE";
    case OtaState::Downloading:
      return "DOWNLOADING";
    case OtaState::Downloaded:
      return "DOWNLOADED";
    case OtaState::Verified:
      return "VERIFIED";
    case OtaState::Updating:
      return "UPDATING";
    case OtaState::Updated:
      return "UPDATED";
    case OtaState::Failed:
      return "FAILED";
  }
  return "";
}

Ota::Ota() : writer_(platformFirmwareWriter()), http_(platformHttpSource()), target_() {}

Result Ota::begin(const char* title, const char* version) {
  if (!title || !title[0] || !version || !version[0]) return Result::Rejected;
  size_t t = strlen(title), v = strlen(version);
  if (t >= sizeof(title_) || v >= sizeof(version_)) return Result::TooLarge;
  memcpy(title_, title, t + 1);
  memcpy(version_, version, v + 1);
  begun_ = true;
  return Result::Ok;
}

void Ota::topics(TopicSink& sink) {
  sink.add(InTopic::AttrUpdate);
  sink.add(InTopic::AttrResponse);
  sink.add(InTopic::FwChunk);
}

bool Ota::handle(const Topic& topic, Bytes payload) {
  if (!client_) return false;
  switch (topic.kind) {
    case InTopic::AttrResponse:
      return client_->resolvePending(topic.id, payload.data(), payload.size());
    case InTopic::AttrUpdate:
      return begun_ && applyAttributes(JsonValue::parse(payload), false);
    case InTopic::FwChunk:
      onChunk(topic, payload);
      return true;
    default:
      return false;
  }
}

void Ota::bootCheck(uint64_t nowMs) {
  if (booted_ || !writer_) return;
  booted_ = true;
  pendingConfirm_ = writer_->pendingConfirm();
  rolledBack_ = writer_->rolledBack();
  confirmDeadline_ = nowMs + VL_OTA_CONFIRM_TIMEOUT_MS;
}

void Ota::onOnline() {
  if (!begun_ || !client_) return;
  uint64_t now = client_->uptimeMs();
  bootCheck(now);
  if (pendingConfirm_) {
    // Connected once: the new image is good, so cancel the rollback.
    pendingConfirm_ = false;
    writer_->confirm();
    VL_LOGI("ota: new firmware confirmed");
  }
  if (!infoSent_) {
    char buf[2 * (VL_OTA_TITLE_SIZE + VL_OTA_VERSION_SIZE) + 48];
    JsonWriter w(buf, sizeof(buf));
    codec::fwInfo(w, title_, version_);
    infoSent_ = sendTelemetry(w);
  }
  requestTarget(now);
  // Resume at the current chunk with a new request id.
  if (phase_ == Phase::Downloading && !target_.url[0]) requestChunk(now);
}

void Ota::tick(uint64_t nowMs) {
  if (!begun_ || !client_) return;
  bootCheck(nowMs);
  if (pendingConfirm_ && nowMs >= confirmDeadline_) {
    pendingConfirm_ = false;
    VL_LOGE("ota: new firmware never came online, rolling back");
    writer_->rollback();
  }
  if (needTarget_ && client_->online() && nowMs >= targetRetryAt_) requestTarget(nowMs);
  if (phase_ == Phase::Downloading) {
    if (target_.url[0]) {
      httpStep(nowMs);
    } else if (deadline_ && nowMs >= deadline_) {
      if (++retries_ > VL_OTA_RETRIES) {
        fail("chunk timeout");
        return;
      }
      VL_LOGW("ota: chunk %lu timed out, retry %u of %u", static_cast<unsigned long>(chunk_),
              static_cast<unsigned>(retries_), static_cast<unsigned>(VL_OTA_RETRIES));
      requestChunk(nowMs);
    }
  } else if (phase_ == Phase::Updating && !restarting_) {
    // Restart once fw_state UPDATING is delivered, or when the wait runs out.
    if (nowMs >= restartAt_ || client_->stats().queuedRecords == 0) {
      restarting_ = true;
      VL_LOGI("ota: restarting into %s %s", target_.title, target_.version);
      writer_->restart();
    }
  }
}

void Ota::onDetach() {
  abortDownload();
  if (phase_ == Phase::Downloading) {
    phase_ = Phase::Idle;
    target_ = Target();
  }
  targetReq_ = 0;
  ApiModule::onDetach();
}

void Ota::requestTarget(uint64_t nowMs) {
  needTarget_ = false;
  if (targetReq_) {
    client_->cancelPending(targetReq_);
    targetReq_ = 0;
  }
  uint32_t id = client_->addPending(VL_ATTR_TIMEOUT_MS, onTargetResponse, this, this);
  if (id != 0) {
    char buf[sizeof(kTargetKeys) + 24];
    JsonWriter w(buf, sizeof(buf));
    codec::attributeRequest(w, nullptr, kTargetKeys);
    RecordMeta m;
    m.topic = OutTopic::AttrRequest;
    m.cls = RecordClass::Control;
    m.arg = id;
    if (ok(client_->enqueue(m, reinterpret_cast<const uint8_t*>(buf), w.size()))) {
      targetReq_ = id;
      return;
    }
    client_->cancelPending(id);
  }
  needTarget_ = true;
  targetRetryAt_ = nowMs + VL_OTA_RETRY_DELAY_MS;
}

void Ota::onTargetResponse(Result r, const uint8_t* p, size_t n, void* ctx) {
  Ota* o = static_cast<Ota*>(ctx);
  o->targetReq_ = 0;
  if (r == Result::Timeout) {
    o->needTarget_ = true;
    o->targetRetryAt_ = 0;
    return;
  }
  if (r != Result::Ok) return;  // NotReady: the client stopped
  o->applyAttributes(JsonValue::parse(reinterpret_cast<const char*>(p), n)["shared"], true);
}

bool Ota::applyAttributes(JsonValue attrs, bool full) {
  if (attrs.type() != JsonValue::Type::Object) {
    if (full) unassign();
    return false;
  }
  if (!attrs["fw_title"].valid()) {
    JsonValue deleted = attrs["deleted"];
    bool removed = false;
    for (size_t i = 0; i < deleted.size() && !removed; ++i) removed = deleted.at(i).equals("fw_title");
    if (full || removed) unassign();
    return removed;
  }
  Target t = Target();
  const char* error = nullptr;
  long long size = attrs["fw_size"].asInt(0);
  if (!copyAttr(attrs["fw_title"], t.title, sizeof(t.title)) ||
      !copyAttr(attrs["fw_version"], t.version, sizeof(t.version)) || !t.title[0] || !t.version[0]) {
    error = "invalid fw_title or fw_version";
  } else if (!copyAttr(attrs["fw_url"], t.url, sizeof(t.url))) {
    error = "fw_url too long";
  } else if (!copyAttr(attrs["fw_checksum"], t.checksum, sizeof(t.checksum)) ||
             !copyAttr(attrs["fw_checksum_algorithm"], t.algoName, sizeof(t.algoName))) {
    error = "invalid fw_checksum";
  } else if (size < 0 || static_cast<unsigned long long>(size) > static_cast<size_t>(-1)) {
    error = "invalid fw_size";
  } else {
    t.size = static_cast<size_t>(size);
  }
  applyTarget(t, error);
  return true;
}

void Ota::applyTarget(const Target& t, const char* error) {
  if (phase_ == Phase::Updating) return;  // the new image boots shortly
  bool same = strcmp(t.title, target_.title) == 0 && strcmp(t.version, target_.version) == 0 &&
              strcmp(t.checksum, target_.checksum) == 0 && strcmp(t.algoName, target_.algoName) == 0 &&
              strcmp(t.url, target_.url) == 0 && t.size == target_.size;
  if (same && phase_ != Phase::Idle) return;  // already downloading, failed or up to date
  abortDownload();
  target_ = t;
  if (strcmp(t.title, title_) == 0 && strcmp(t.version, version_) == 0) {
    phase_ = Phase::Updated;
    rolledBack_ = false;
    if (!updatedSent_) {
      updatedSent_ = true;
      report(OtaState::Updated);
    }
    return;
  }
  if (rolledBack_) {
    // Most likely the package that was just rolled back: never loop on it.
    rolledBack_ = false;
    fail("rolled back");
    return;
  }
  if (error) {
    fail(error);
    return;
  }
  startDownload();
}

void Ota::unassign() {
  if (phase_ == Phase::Updating) return;
  abortDownload();
  target_ = Target();
  phase_ = Phase::Idle;
}

void Ota::startDownload() {
  bool url = target_.url[0] != '\0';
  verify_ = target_.checksum[0] && target_.algoName[0];
  if (verify_ && !parseHashAlgo(target_.algoName, algo_)) {
    fail("unsupported checksum algorithm");
    return;
  }
#if !VL_OTA_ALLOW_UNVERIFIED
  if (!verify_) {
    fail("no checksum");
    return;
  }
#endif
  if (!url && target_.size == 0) {
    fail("no fw_size");
    return;
  }
  if (!writer_) {
    fail("no firmware writer");
    return;
  }
  if (url && !http_) {
    fail("no HTTP client");
    return;
  }
  if (!url) {
    size_t packet = client_->maxPacket();
    if (packet > kServerMaxPayload) packet = kServerMaxPayload;
    chunkSize_ = packet > kChunkOverhead ? packet - kChunkOverhead : 0;
    if (VL_OTA_CHUNK_SIZE != 0 && VL_OTA_CHUNK_SIZE < chunkSize_) chunkSize_ = VL_OTA_CHUNK_SIZE;
    if (chunkSize_ == 0) {
      fail("transport buffer too small");
      return;
    }
  }
  Result r = writer_->begin(target_.size);
  if (r != Result::Ok) {
    fail(r == Result::TooLarge ? "image too large" : "flash not ready");
    return;
  }
  writerOpen_ = true;
  if (verify_) hasher_.begin(algo_);
  written_ = 0;
  expected_ = target_.size;
  chunk_ = 0;
  retries_ = 0;
  firstReq_ = nextReq_;
  phase_ = Phase::Downloading;
  VL_LOGI("ota: downloading %s %s", target_.title, target_.version);
  report(OtaState::Downloading);
  uint64_t now = client_->uptimeMs();
  if (url) {
    deadline_ = now;  // httpStep() opens the connection
  } else {
    requestChunk(now);
  }
}

void Ota::requestChunk(uint64_t nowMs) {
  deadline_ = 0;
  if (!client_->online()) return;  // onOnline() asks again
  char body[12];
  int n = snprintf(body, sizeof(body), "%lu", static_cast<unsigned long>(chunkSize_));
  RecordMeta m;
  m.topic = OutTopic::FwChunkRequest;
  m.cls = RecordClass::Control;
  m.arg = nextReq_++;
  m.arg2 = chunk_;
  Result r = client_->enqueue(m, reinterpret_cast<const uint8_t*>(body), static_cast<size_t>(n));
  // A refused request is retried like a lost one.
  deadline_ = nowMs + (ok(r) ? VL_OTA_CHUNK_TIMEOUT_MS : VL_OTA_RETRY_DELAY_MS);
}

void Ota::onChunk(const Topic& topic, Bytes payload) {
  // Responses to earlier requests, or for a chunk already written, are dropped.
  if (phase_ != Phase::Downloading || target_.url[0] || topic.id < firstReq_ || topic.id >= nextReq_ ||
      topic.id2 != chunk_) {
    return;
  }
  size_t left = expected_ - written_;
  size_t n = payload.size() < left ? payload.size() : left;
  if (n == 0) {
    fail("image shorter than fw_size");
    return;
  }
  if (n < chunkSize_ && n < left) {
    fail("short chunk");
    return;
  }
  if (!consume(payload.data(), n)) return;
  retries_ = 0;
  ++chunk_;
  if (written_ >= expected_) {
    finishDownload();
  } else {
    requestChunk(client_->uptimeMs());
  }
}

void Ota::httpStep(uint64_t nowMs) {
  if (!httpOpen_) {
    if (nowMs < deadline_) return;
    size_t start = 0, total = 0;
    const ITlsProvider* tls = httpTls_ ? httpTls_ : client_->tls();
    if (http_->open(target_.url, written_, tls, start, total) != Result::Ok) {
      httpRetry(nowMs, "download failed");
      return;
    }
    httpOpen_ = true;
    if (start != written_) {
      // The server ignored the Range request: start the image over.
      VL_LOGW("ota: server cannot resume, download restarts");
      writer_->abort();
      writerOpen_ = false;
      if (start != 0 || writer_->begin(target_.size) != Result::Ok) {
        fail("download restart failed");
        return;
      }
      writerOpen_ = true;
      if (verify_) hasher_.begin(algo_);
      written_ = 0;
    }
    if (!expected_) expected_ = total;
  }
  uint8_t buf[VL_OTA_HTTP_BLOCK];
  size_t want = sizeof(buf);
  if (expected_ && expected_ - written_ < want) want = expected_ - written_;
  int n = http_->read(buf, want);
  if (n > 0) {
    if (!consume(buf, static_cast<size_t>(n))) return;
    retries_ = 0;
    if (expected_ && written_ >= expected_) finishDownload();
    return;
  }
  http_->close();
  httpOpen_ = false;
  if (n == 0 && (expected_ ? written_ >= expected_ : written_ > 0)) {
    finishDownload();
    return;
  }
  httpRetry(nowMs, n == 0 ? "download incomplete" : "download failed");
}

void Ota::httpRetry(uint64_t nowMs, const char* error) {
  if (++retries_ > VL_OTA_RETRIES) {
    fail(error);
    return;
  }
  VL_LOGW("ota: %s, retry %u of %u", error, static_cast<unsigned>(retries_), static_cast<unsigned>(VL_OTA_RETRIES));
  deadline_ = nowMs + VL_OTA_RETRY_DELAY_MS;
}

bool Ota::consume(const uint8_t* p, size_t n) {
  if (writer_->write(p, n) != Result::Ok) {
    fail("flash write failed");
    return false;
  }
  if (verify_) hasher_.update(p, n);
  written_ += n;
  if (progressCb_) progressCb_(written_, expected_, progressCtx_);
  return true;
}

void Ota::finishDownload() {
  if (httpOpen_) {
    http_->close();
    httpOpen_ = false;
  }
  deadline_ = 0;
  report(OtaState::Downloaded);
  if (verify_) {
    char hex[Hasher::kHexSize];
    hasher_.hex(hex);
    if (!equalsHex(hex, target_.checksum)) {
      VL_LOGE("ota: checksum %s, expected %s", hex, target_.checksum);
      fail("checksum mismatch");
      return;
    }
    report(OtaState::Verified);
  }
  writerOpen_ = false;
  if (writer_->finish() != Result::Ok) {
    writer_->abort();
    fail("image rejected");
    return;
  }
  phase_ = Phase::Updating;
  report(OtaState::Updating);
  restartAt_ = client_->uptimeMs() + VL_OTA_RESTART_DELAY_MS;
}

void Ota::abortDownload() {
  if (httpOpen_) {
    http_->close();
    httpOpen_ = false;
  }
  if (writerOpen_) {
    writer_->abort();
    writerOpen_ = false;
  }
  deadline_ = 0;
}

void Ota::fail(const char* error) {
  abortDownload();
  phase_ = Phase::Failed;
  VL_LOGE("ota: %s %s failed: %s", target_.title, target_.version, error);
  report(OtaState::Failed, error);
}

bool Ota::sendTelemetry(const JsonWriter& w) {
  if (w.overflowed()) return false;
  RecordMeta m = client_->stampedMeta(OutTopic::Telemetry, kNoDevice);
  m.cls = RecordClass::Control;  // never dropped with data
  return ok(client_->enqueue(m, reinterpret_cast<const uint8_t*>(w.c_str()), w.size()));
}

void Ota::report(OtaState s, const char* error) {
  state_ = s;
  if (client_) {
    char buf[96];
    JsonWriter w(buf, sizeof(buf));
    codec::fwState(w, toString(s), error);
    if (!sendTelemetry(w)) VL_LOGW("ota: fw_state %s not queued", toString(s));
  }
  if (stateCb_) stateCb_(s, error, stateCtx_);
}

}  // namespace vl

#endif  // VL_ENABLE_OTA
```

```cpp
#if VL_PLATFORM_ESP32

#include <stdio.h>
#include <string.h>

#include "esp_http_client.h"
#include "esp_ota_ops.h"
#include "esp_system.h"
#include "vl/Log.h"

#if defined(CONFIG_MBEDTLS_CERTIFICATE_BUNDLE)
// See EspMqtt.cpp: arduino-esp32 shadows IDF's esp_crt_bundle.h.
extern "C" esp_err_t esp_crt_bundle_attach(void* conf);
#define VL_HTTP_CRT_BUNDLE 1
#else
#define VL_HTTP_CRT_BUNDLE 0
#endif

namespace vl {

IFirmwareWriter* platformFirmwareWriter() {
  static EspFirmwareWriter writer;
  return &writer;
}

IHttpSource* platformHttpSource() {
  static EspHttpSource source;
  return &source;

Result EspFirmwareWriter::begin(size_t size) {
  abort();
  const esp_partition_t* p = esp_ota_get_next_update_partition(nullptr);
  if (!p) {
    VL_LOGE("ota: no OTA app partition (check the partition table)");
    return Result::NotReady;
  }
  if (size > p->size) return Result::TooLarge;
  // Erasing the whole slot up front would stall the client task for seconds.
  esp_ota_handle_t h = 0;
  esp_err_t err = esp_ota_begin(p, OTA_WITH_SEQUENTIAL_WRITES, &h);
  if (err != ESP_OK) {
    VL_LOGE("ota: esp_ota_begin: %s", esp_err_to_name(err));
    return Result::Rejected;
  }
  part_ = p;
  handle_ = h;
  open_ = true;
  return Result::Ok;
}

Result EspFirmwareWriter::write(const uint8_t* p, size_t n) {
  if (!open_) return Result::NotReady;
  esp_err_t err = esp_ota_write(handle_, p, n);
  if (err != ESP_OK) {
    VL_LOGE("ota: esp_ota_write: %s", esp_err_to_name(err));
    return Result::Rejected;
  }
  return Result::Ok;
}

Result EspFirmwareWriter::finish() {
  if (!open_) return Result::NotReady;
  open_ = false;
  esp_err_t err = esp_ota_end(handle_);  // checks the image header and digest
  if (err == ESP_OK) err = esp_ota_set_boot_partition(static_cast<const esp_partition_t*>(part_));
  if (err != ESP_OK) {
    VL_LOGE("ota: activation failed: %s", esp_err_to_name(err));
    return Result::Rejected;
  }
  return Result::Ok;
}

void EspFirmwareWriter::abort() {
  if (!open_) return;
  open_ = false;
  esp_ota_abort(handle_);
}

void EspFirmwareWriter::restart() { esp_restart(); }

bool EspFirmwareWriter::pendingConfirm() {
  esp_ota_img_states_t st;
  return esp_ota_get_state_partition(esp_ota_get_running_partition(), &st) == ESP_OK &&
         st == ESP_OTA_IMG_PENDING_VERIFY;
}

void EspFirmwareWriter::confirm() { esp_ota_mark_app_valid_cancel_rollback(); }

void EspFirmwareWriter::rollback() { esp_ota_mark_app_invalid_rollback_and_reboot(); }

bool EspFirmwareWriter::rolledBack() { return esp_ota_get_last_invalid_partition() != nullptr; }

Result EspHttpSource::open(const char* url, size_t offset, const ITlsProvider* tls, size_t& start, size_t& total) {
  close();
  esp_http_client_config_t c;
  memset(&c, 0, sizeof(c));
  c.url = url;
  c.timeout_ms = VL_OTA_HTTP_TIMEOUT_MS;
  c.cert_pem = tls ? tls->caPem() : nullptr;
#if VL_HTTP_CRT_BUNDLE
  if (!c.cert_pem) c.crt_bundle_attach = esp_crt_bundle_attach;
#endif
  esp_http_client_handle_t h = esp_http_client_init(&c);
  if (!h) return Result::NoMemory;
  client_ = h;
  if (offset) {
    char range[32];
    snprintf(range, sizeof(range), "bytes=%lu-", static_cast<unsigned long>(offset));
    esp_http_client_set_header(h, "Range", range);
  }
  long long len = -1;
  int status = 0;
  for (int hop = 0;; ++hop) {
    esp_err_t err = esp_http_client_open(h, 0);
    if (err != ESP_OK) {
      VL_LOGW("ota: HTTP open failed: %s", esp_err_to_name(err));
      close();
      return Result::Rejected;
    }
    len = esp_http_client_fetch_headers(h);
    status = esp_http_client_get_status_code(h);
    bool redirect = status == 301 || status == 302 || status == 303 || status == 307 || status == 308;
    if (!redirect || hop == 3) break;
    esp_http_client_set_redirection(h);
    esp_http_client_close(h);
  }
  if (status != 200 && status != 206) {
    VL_LOGW("ota: HTTP status %d", status);
    close();
    return Result::Rejected;
  }
  start = status == 206 ? offset : 0;
  total = len > 0 ? start + static_cast<size_t>(len) : 0;
  return Result::Ok;
}

int EspHttpSource::read(uint8_t* buf, size_t cap) {
  esp_http_client_handle_t h = static_cast<esp_http_client_handle_t>(client_);
  if (!h) return -1;
  int n = esp_http_client_read(h, reinterpret_cast<char*>(buf), static_cast<int>(cap));
  if (n > 0) return n;
  return esp_http_client_is_complete_data_received(h) ? 0 : -1;
}

void EspHttpSource::close() {
  esp_http_client_handle_t h = static_cast<esp_http_client_handle_t>(client_);
  if (!h) return;
  client_ = nullptr;
  esp_http_client_close(h);
  esp_http_client_cleanup(h);
}
```

```cpp
// Firmware updates from ViraLink Console (ThingsBoard OTA packages).
//
// - Upload a package with title "ota-demo" and a newer version, then assign
//   it to this device (or its device profile). A package made from a file
//   arrives in MQTT chunks; one made from a URL is downloaded over HTTPS.
// - The image is checked against the package checksum, the new slot is
//   activated, and the device restarts into it. fw_state on the device's
//   page follows each step.
// - With CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE (ESP-IDF menuconfig), an image
//   that never connects is rolled back after VL_OTA_CONFIRM_TIMEOUT_MS or a
//   crash; with the Arduino core's default bootloader it stays installed.
//
// Build the new firmware with FW_VERSION changed to the package's version.

#include <WiFi.h>
#include <ViraLink.h>
#include <time.h>

static const char* WIFI_SSID = "your-ssid";
static const char* WIFI_PASS = "your-password";
static const char* VL_HOST = "console.viralink.ir";
static const char* VL_TOKEN = "YOUR_DEVICE_TOKEN";

static const char* FW_TITLE = "ota-demo";
static const char* FW_VERSION = "1.0.0";

vl::EspMqtt mqtt;
vl::RingOutbox<8 * 1024> outbox;
vl::Client client(mqtt, outbox);
vl::Ota ota;

static uint32_t lastPrintMs = 0;

static void onOtaState(vl::OtaState state, const char* error, void* /*ctx*/) {
  if (error) {
    Serial.printf("ota: %s (%s)\n", vl::toString(state), error);
  } else {
    Serial.printf("ota: %s\n", vl::toString(state));
  }
}

static void onOtaProgress(size_t done, size_t total, void* /*ctx*/) {
  uint32_t now = millis();
  if (now - lastPrintMs < 2000 && done != total) return;
  lastPrintMs = now;
  if (total) {
    Serial.printf("ota: %u of %u bytes\n", static_cast<unsigned>(done), static_cast<unsigned>(total));
  } else {
    Serial.printf("ota: %u bytes\n", static_cast<unsigned>(done));
  }
}

void setup() {
  Serial.begin(115200);
  Serial.printf("running %s %s\n", FW_TITLE, FW_VERSION);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  configTime(0, 0, "pool.ntp.org");

  ota.begin(FW_TITLE, FW_VERSION);
  ota.onState(onOtaState, nullptr);
  ota.onProgress(onOtaProgress, nullptr);
  client.use(ota);

  client.onState([](vl::State s, void*) { Serial.printf("state: %s\n", vl::toString(s)); }, nullptr);

  vl::Config cfg;
  cfg.host = VL_HOST;
  cfg.auth = vl::AccessToken(VL_TOKEN);
  client.begin(cfg);
}

void loop() {
  client.loop();
  delay(5);
}
```

````markdown
### OTA

Firmware updates use ThingsBoard OTA packages: assign one to the device or
its profile and the device installs it.

```cpp
vl::Ota ota;
ota.begin("ViraGate", "2.3.0");  // the running firmware's title and version
ota.onState([](vl::OtaState s, const char* error, void*) { /* log, LEDs */ }, nullptr);
client.use(ota);
```

- A package made from a file arrives over MQTT in chunks as large as the
  transport buffer allows; a package made from a URL (`fw_url`) is
  downloaded over HTTP(S), resuming with a `Range` request after a break.
  HTTPS trusts `Config::tls`, or `ota.setHttpTls()`, or on ESP32 the
  certificate bundle.
- Every checksum algorithm ThingsBoard offers is checked while the image is
  written: MD5, SHA256, SHA384, SHA512, CRC32, MURMUR3_32 and MURMUR3_128.
  A package without a checksum is refused unless `VL_OTA_ALLOW_UNVERIFIED` is 1.
- `fw_state` goes through DOWNLOADING, DOWNLOADED, VERIFIED and UPDATING;
  the device then restarts into the new image, which reports UPDATED. A
  failure reports FAILED with `fw_error`. A failed package is not tried
  again until it is reassigned, another one is assigned, or the device
  restarts.
- On ESP32 the image goes to the next OTA partition. With
  `CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE`, a new image is confirmed on its
  first connection and rolled back if it crashes or is not online within
  `VL_OTA_CONFIRM_TIMEOUT_MS` (5 minutes); the package it came from then
  reports FAILED "rolled back" instead of being installed again.
- Other targets need an `IFirmwareWriter` (and an `IHttpSource` for URL
  packages) passed to `ota.setWriter()` / `ota.setHttp()`.
- The download blocks `loop()` for at most one chunk write, or one HTTP read
  of `VL_OTA_HTTP_BLOCK` bytes (up to `VL_OTA_HTTP_TIMEOUT_MS` on a stalled link).
````
